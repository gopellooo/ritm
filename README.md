# Ритм

Русскоязычный планировщик беговых маршрутов. Выбери старт на карте или определи местоположение, задай дистанцию от 1 до 40 км и выбери кольцо или маршрут туда-обратно. Готовый трек можно скачать в GPX. При открытии показан пример маршрута длиной 5,05 км в Парке Горького в Москве.

Доступны четыре режима.

- **Кольцо** строит маршрут выбранной длины с возвратом к старту.
- **Туда-обратно** прокладывает путь до точки разворота и назад.
- **По точкам** проходит через 2–10 отметок в выбранном порядке. Первая отметка — старт, последняя — финиш.
- **Точки + дистанция** проходит через 2–3 отметки и добавляет участок, чтобы приблизиться к заданной длине. Первая отметка — старт, последняя — финиш. Допустимое отклонение от цели составляет 8,5% или 100 м для коротких маршрутов. Если кратчайший путь уже длиннее цели или подходящий вариант не найден, приложение показывает ошибку.

Планировщик ищет пешеходную дорожку в пределах 35 м от каждой выбранной отметки. Если связать все точки не получается или маршрут длиннее 40 км, он показывает ошибку. На телефоне настройки можно свернуть, а кнопка построения остаётся в нижней части экрана. Карточки точек располагаются в одну строку и прокручиваются горизонтально, одновременно видны примерно 2–3 карточки.

## Запуск

Это статическое приложение без сборки и API-ключей. Открой файлы через HTTP-сервер. Для геолокации нужен HTTPS или `localhost`.

```sh
python -m http.server 8091
```

В репозитории на GitHub файлы сайта находятся в корне. Для GitHub Pages выбери **Settings → Pages → Deploy from a branch → main → / (root)**.

## Карта и маршрутизация

- [OpenFreeMap](https://openfreemap.org/) и [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) отображают карту на данных [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Пешеходный [демосервер OSRM от FOSSGIS](https://routing.openstreetmap.de/about.html) подходит для небольшой некоммерческой нагрузки. Маршрутизатор получает координаты точек и указывает, что сохраняет запросы в журнале. Клиент отправляет запросы с интервалом от 1,1 секунды. При большом трафике понадобится отдельный маршрутизатор.
- Кольцо и маршрут туда-обратно используют до трёх запросов, а режим с точками и дистанцией — до пяти. На экране показывается фактическая длина.
