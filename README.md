# Ритм

Русскоязычный планировщик беговых маршрутов. Выбери старт на карте или определи местоположение, задай дистанцию от 1 до 40 км и выбери кольцо или маршрут туда-обратно. Готовый трек можно скачать в GPX. При открытии показан пример маршрута длиной 5,05 км в Парке Горького в Москве.

В режиме **По точкам** отметь на карте 2 или 3 точки в нужном порядке и нажми **Построить маршрут**. Выбери **В другой точке**, чтобы последняя отметка стала финишем, или **В точке старта**, чтобы вернуться к первой отметке. Планировщик ищет пешеходную дорожку в пределах 35 м от каждой отметки. Если связать все точки не получается или маршрут длиннее 40 км, он показывает ошибку.

## Запуск

Это статическое приложение без сборки и API-ключей. Открой файлы через HTTP-сервер. Для геолокации нужен HTTPS или `localhost`.

```sh
python -m http.server 8091
```

В репозитории на GitHub файлы сайта находятся в корне. Для GitHub Pages выбери **Settings → Pages → Deploy from a branch → main → / (root)**.

## Карта и маршрутизация

- [OpenFreeMap](https://openfreemap.org/) и [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) отображают карту на данных [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Пешеходный [демосервер OSRM от FOSSGIS](https://routing.openstreetmap.de/about.html) подходит для небольшой некоммерческой нагрузки. Маршрутизатор получает координаты точек и указывает, что сохраняет запросы в журнале. Клиент отправляет запросы с интервалом от 1,1 секунды. При большом трафике понадобится отдельный маршрутизатор.
- Планировщик запрашивает до трёх вариантов, учитывает отклонение от заданного километража и по возможности сокращает повторы участков. На экране показывается фактическая длина.
